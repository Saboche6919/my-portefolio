

\# Carine's World



Portfolio personnel de Carine BAKA, étudiante en Pré-MSc à Epitech.



\## Objectif



Présenter mes projets, mes compétences et ma progression

dans le développement informatique.



\## Technologies



\- HTML

\- CSS

\- Git et GitHub



\## Structure



\- index.html : accueil

\- apropos.html : présentation

\- competences.html : compétences et apprentissages

\- projets.html : réalisations

\- contact.html : formulaire et coordonnées

\- style.css : mise en forme et responsive

\- images/ : illustrations et captures d'écran

\- documents/ : CV au format PDF



\## Consulter le site



Ouvrir index.html dans un navigateur.



\## Publication



Le portfolio est prévu pour être publié avec GitHub Pages,

depuis la branche principale du dépôt.



Une fois GitHub Pages activé, les modifications poussées

sur la branche publiée seront automatiquement mises en ligne.



\## Évolution



Ce portfolio sera régulièrement mis à jour avec

mes nouveaux projets et mes apprentissages.
