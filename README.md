

\# 🌸 Carine's World



Bienvenue sur \*\*Carine's World\*\*, mon portfolio personnel réalisé dans le cadre de mon parcours en Pré-MSc à Epitech.



Ce site présente mon parcours, mes compétences, mes projets et mon évolution dans le développement informatique.



\## 🌐 Site en ligne



\*\*\[Découvrir mon portfolio](https://saboche6919.github.io/my-portefolio/)\*\*



\## 🎯 Objectif



Ce portfolio me permet de :



\- Présenter mon parcours et ma reconversion vers l'informatique.

\- Mettre en valeur les compétences acquises pendant ma formation.

\- Partager mes projets et mes réalisations.

\- Suivre ma progression au fil de mes apprentissages.

\- Faciliter la prise de contact dans le cadre de ma recherche d'alternance.



\## 💻 Technologies utilisées



Le portfolio est développé avec :



\- \*\*HTML5\*\* : structure et contenu des pages.

\- \*\*CSS3\*\* : design, animations et adaptation aux écrans.

\- \*\*JavaScript\*\* : interactions du site.

\- \*\*Git\*\* : suivi des modifications.

\- \*\*GitHub\*\* : hébergement du code.

\- \*\*GitHub Pages\*\* : publication du site.



\## 🎨 Design



J'ai choisi une identité visuelle douce et personnelle :



\- Palette rose, pêche et blanc.

\- Avatar kawaii.

\- Curseur personnalisé en forme de patte.

\- Animations légères.

\- Navigation simple et responsive.



L'objectif est de proposer un portfolio à la fois professionnel, accessible et fidèle à ma personnalité.

| Fichier | Rôle |

|---|---|

| `index.html` | Page d'accueil et présentation rapide |

| `apropos.html` | Parcours et reconversion |

| `competences.html` | Compétences et apprentissages |

| `projets.html` | Projets réalisés et en préparation |

| `contact.html` | Formulaire de contact, liens et CV |

| `style.css` | Apparence, animations et responsive |

| `script.js` | Fonctionnalités JavaScript |



\## 🚀 Installation locale



1\. Cloner le dépôt :



```bash

git clone https://github.com/Saboche6919/my-portefolio.git

```



2\. Ouvrir le dossier `my-portefolio`.



3\. Ouvrir `index.html` dans un navigateur.



Aucune installation de dépendances n'est nécessaire.
